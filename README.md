# ZalogHub To-Do List

Приложение для управления задачами, разработанное на React и TypeScript.

## Технологии

- React
- TypeScript
- Vite
- CSS
- LocalStorage

## Функциональность

- Добавление задач
- Отметка выполнения
- Удаление задач
- Фильтрация задач
- Сохранение данных в LocalStorage

## Запуск проекта

Установить зависимости:

npm install

Запустить проект:

npm run dev

## Время выполнения

Примерное время выполнения: 50 минут.
